# Rally — sport, in your corner

A responsive, static sports experience with a fresh visual identity. Rally blends a live-score ticker, sports filters, match cards, a simulated picks slip, match snapshots, and a compact editorial feature into one fan-focused dashboard.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required. Google Fonts are loaded remotely; system fallbacks are included.

## Demo interactions

- Browse the fixture list and filter by sport.
- Select fictional match outcomes to build a picks slip.
- Adjust demo points to see a calculated possible return.
- Search today's fixture list, or try the quick stake buttons.
- The submit action only shows a confirmation and clears the demo slip.

**This is a non-functional product prototype.** It does not take bets, handle accounts, accept deposits, or award cash prizes. All teams, odds, scores, and event data are illustrative placeholders and are not live data. The demo points have no monetary value.
